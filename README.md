# Data Science Projects

This repository contains practical projects completed as part of a **Data Science course**. The projects apply data analysis techniques to different business scenarios, from understanding customer behavior to evaluating market trends and supporting data-driven decisions.

All project notebooks are written in **Russian**. The descriptions below are provided in English to make the repository easier to navigate.

## Projects

### 1. GoFast User Data Analysis
Analysis of user activity and behavior for a scooter-sharing service. The project explores usage patterns and customer characteristics to derive insights that can support business decisions.

### 2. Video Game Market Analysis
Market research for an online video game retailer. The project examines sales trends, platform performance, game genres, and customer preferences to identify patterns that can inform business and marketing decisions.

### 3. Oil Well Location Selection
Data-driven evaluation of potential locations for new oil wells. The project applies predictive modeling and risk assessment to compare locations and support investment decisions.

### 4. Apartment Listing Analysis
Exploratory analysis of apartment listings to investigate property characteristics, pricing patterns, and the factors associated with differences in apartment prices.

## Skills and Techniques

These projects provided practical experience in:

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Statistical analysis and hypothesis testing
- Data visualization and interpretation
- Machine learning and predictive modeling
- Business-oriented analysis and data-driven decision-making
